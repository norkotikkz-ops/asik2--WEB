How it's built

.portfolio is display: grid with grid-template-columns: 2fr 1fr, splitting the page into a projects column and an info column. Inside that, .projects is a flex column stacking the project cards, and each .project-card is itself a flex row placing a number badge next to its text — Grid for the page, Flexbox for the content inside it.
