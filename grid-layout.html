How it's built

The .dash container defines grid-template-columns: 220px 1fr, grid-template-rows: auto 1fr auto, and a grid-template-areas string with four named regions. Each child is placed with grid-area, so re-ordering the layout is a one-line change to the area string rather than renumbering rows and columns.
