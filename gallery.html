Task 3 · CSS Grid

Image gallery

Nine tiles in a three-column grid. Hover (or focus) a tile to reveal its caption.

How it's built

.gallery is display: grid with grid-template-columns: repeat(3, 1fr) and a fixed gap, so every tile stays equal width. Each caption is an absolutely-positioned figcaption that sits at opacity: 0 until the tile is hovered or focused, which also makes the effect reachable by keyboard.
